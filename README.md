## 1. 系统概述

**研发OA综合平台**是前卫表业工程技术研究中心自主建设的内部办公自动化综合平台，旨在解决研发过程中知识分散、标准难以检索、绩效考核流程不透明、过程资产无沉淀等痛点。平台采用 **OA 门户** 式信息架构——工作台 → 板块 → 子系统三级磁贴导航，提供**统一入口、统一账号、统一权限**的一站式办公体验，覆盖研发团队日常工作的核心场景。

### 核心特点

| 特点 | 说明 |
|------|------|
| 纯前端原型 | 无后端依赖，直接用浏览器打开即可运行 |
| 权限驱动 | 菜单、按钮、数据全部按角色权限动态展示 |
| 三级审核 | 经验案例入库、绩效考核等均走标准化审批流 |
| 水印防护 | 在线预览 PDF 自动叠加「用户名+时间」动态水印 |
| 待办聚合 | 工作台与右上角铃铛统一收集跨模块待办事项，实时提醒 |
| 全局搜索 | 顶部搜索框跨「研发公共 + 过程资产」检索，独立结果页 + 详情弹窗 |
| 通知公告 | 工作台公告面板（未读提醒）+ 系统管理内公告维护 |
| 常用应用 | 工作台固定常用子系统磁贴，按账号持久化 |
| 外链聚合 | 第三方业务系统通过外部子系统磁贴统一入口 |

### 技术架构

```
前端技术栈：原生 JavaScript + HTML5 + CSS3 + SheetJS (xlsx 解析)
数据存储：  localStorage（会话级）+ localStorage（持久级）
路由方案：  自定义门户路由（工作台 → 板块首页 → 子系统页）+ sessionStorage 持久化
```

## 2. 运行环境与启动方式

### 运行环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 90+、Edge 90+、Firefox 90+、Safari 14+ |
| 操作系统 | Windows 10/11、macOS、Linux |
| Node.js（可选） | 用于启动本地静态服务器 |

### 启动方式

**方式一：直接打开（推荐原型演示）**
```
直接双击 index.html 文件，用浏览器打开即可
```

**方式二：本地静态服务器（推荐开发调试）**
```bash
# 使用 npx 启动（需 Node.js 环境）
cd rd-oa-platform
npx serve -p 3000

# 或使用 pnpm
pnpm dlx serve -p 3000
```
启动后访问 `http://localhost:3000` 即可。

 ⚠️ **注意**：通过 `file://` 协议打开时，部分浏览器（如 Chrome）的 localStorage 在不同标签页间不共享，且外链跳转可能被拦截。建议使用本地服务器方式访问。

## 3. 登录与认证

### 3.1 登录页面

打开系统后首先进入登录页面，左侧展示公司名称"前卫表业"，右侧为登录表单。

### 3.2 演示账号

系统预置了多组演示账号，点击登录页面底部的标签即可**自动填充账号密码**：

| 工号/账号 | 角色 | 默认密码 | 说明 |
|-----------|------|----------|------|
| **8001** | 一般人员 | `123456` | 普通研发人员，拥有查看和导出权限 |
| **8004** | 项目经理 | `123456` | 可对过程资产进行新增/编辑/删除 |
| **8005** | 主管 | `123456` | 可对下属进行绩效考核打分 |
| **8006** | 部门领导 | `123456` | 最终审核考核表、配置互评人 |
| **admin** | 系统管理员 | `admin123` | 超级管理员，拥有全部权限 |

### 3.3 登录操作步骤

1. 在「用户名 Account」输入框中输入工号或账号
2. 在「密码 Password」输入框中输入对应密码
3. 点击「登 录」按钮
4. 登录成功后进入 OA 门户工作台，按权限点选板块进入

### 3.4 会话保持

- 登录成功后，会话信息持久化到 **sessionStorage**（`oa_session`）
- 刷新页面可自动恢复登录状态和上次浏览位置
- **关闭浏览器标签页** → 会话丢失，需重新登录
- **点击头像下拉 → 切换角色/退出登录** → 清除会话并返回登录页

### 3.5 登录拦截机制

未登录时直接访问系统内部路由会被拦截器拦截，强制跳转回登录页面，有效保护子系统入口安全。

```
┌─────────────────────────────────────────────────────────────────────┐
│ 顶部导航栏 (Header)                                                  │
│ ┌─────────┐ ┌──────────────────────┐              ┌──────────────┐  │
│ │ Logo    │ │ 🔍 全局搜索框         │              │ 时钟 🔔 👤   │  │
│ │(返回工作台)│ │标准/案例/资产 回车搜索│              │              │  │
│ └─────────┘ └──────────────────────┘              └──────────────┘  │
├─────────────────────────────────────────────────────────────────────┤
│ 面包屑（可点击跳转）     工作台 / 研发公共 / 标准库   [← 返回研发公共] │
├─────────────────────────────────────────────────────────────────────┤
│ 主内容区 (Content) —— 全宽展示，只呈现当前层级自身内容                  │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ 工作台：问候语 + 常用应用 + 板块磁贴 + 我的待办｜通知公告        │ │
│ │ 板块首页：该板块下所有子系统磁贴一次性铺开                          │ │
│ │ 子系统页：仅该子系统自身内容                                        │ │
│ │ 搜索页：独立搜索结果列表，点击弹窗查看详情                          │ │
│ └─────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

### 界面各区域说明

| 区域 | 功能说明 |
|------|----------|
| **顶部 Logo** | 点击返回 OA 门户工作台 |
| **🔍 全局搜索框** | 顶部居中，回车触发；搜索范围：研发公共（标准库 / 经验案例库）+ 过程资产（开发规范 / 文档模板 / 设计规范 / 评审 Checklist），按角色权限过滤；结果在独立搜索页展示，点击条目弹窗查看详情 |
| **实时时钟** | 右上角显示当前日期、星期和精确到秒的时间 |
| **🔔 铃铛** | 显示待办事项数量角标，点击可查看全部待办清单 |
| **👤 头像** | 显示当前登录角色，点击弹出下拉菜单 |
| **面包屑** | 显示当前层级路径（工作台 / 板块 / 子系统 / 三级子项），每一级均可点击跳转 |
| **返回条** | 子系统页右上角提供返回按钮：二级子系统页「← 返回板块」回到板块首页；三级子项页「← 返回父级分组」（如「← 返回年度绩效管理」）回到分组磁贴页 |
| **主内容区** | 全宽展示当前页面内容；子系统页只显示该子系统自身，不出现同板块其他子系统入口 |

### 门户导航流程

```
工作台（问候语 + 5 大板块磁贴 + 我的常用应用 + 待办/公告面板，均按角色过滤）
   └── 点击板块磁贴 → 板块首页（该板块全部子系统竖排磁贴铺开，含数量与外链标识，列数拉满）
         └── 点击子系统磁贴 → 子系统页（内容区仅该子系统自身 + 面包屑 + 返回条）
               └── 含三级子项的子系统（如「年度绩效管理」）→ 三级子项分组磁贴页 → 点击磁贴 → 三级子系统页
```

- 每个板块磁贴显示**主题色**、**子系统数量**、**模块描述**与「进入板块 →」链接（竖排大卡片，一行最多 6 个）；
- 「我的常用应用」为横排小磁贴，一行最多 8 个；
- 外部子系统磁贴带「外链」标识，点击在新窗口打开第三方系统；
- 所有磁贴按当前角色权限过滤，无权限的板块/子系统不会出现。

## 5. 角色与权限体系

### 5.1 角色定义

系统内置 **5 个角色**，每个角色拥有不同的菜单和操作权限：

| 角色 | 角色编码 | 默认账号 | 权限范围摘要 |
|------|----------|----------|--------------|
| **一般人员** | `staff` | 8001 | 所有模块的**查看**和**导出**权限，标准管理员功能除外 |
| **项目经理** | `projManager` | 8004 | 在一般人员基础上，额外拥有**过程资产**模块 4 个子菜单的新增/编辑/删除权限 |
| **主管** | `supervisor` | 8005 | 在一般人员基础上，额外拥有**绩效管理**模块的模板管理、月度/年度考核编辑权限 |
| **部门领导** | `deptLeader` | 8006 | 在主管基础上，额外拥有**年终考核汇总**编辑权限、**互评管理**配置权限 |
| **系统管理员** | `sysAdmin` | admin | **超级管理员**，拥有全部模块全部权限，负责账号/角色/菜单/字典/日志管理 |

### 5.2 权限控制维度

系统采用**两级权限控制**模型：

```
┌─────────────────────────────────────┐
│  第一层：模块级权限（菜单可见性）      │
│  角色 → 模块 → 子菜单 → 三级子菜单    │
├─────────────────────────────────────┤
│  第二层：业务级操作权限（按钮可见性）  │
│  每个菜单项可声明 6 种 Action 权限：   │
│  view（查看） add（新增） edit（编辑） │
│  delete（删除） export（导出）admin（管理员）│
└─────────────────────────────────────┘
```

### 5.3 权限配置方法

仅 **系统管理员** 可配置角色权限：

1. 登录 admin 账号
2. 进入「系统管理 → 角色管理」
3. 找到目标角色，点击「权限配置」按钮
4. 在弹窗中勾选各模块/子菜单的访问权限，以及具体的操作权限（查看/新增/编辑/删除/导出/管理员）
5. 点击「💾 保存配置」生效

权限变更后，所有打开该系统的页面会自动刷新菜单，无需手动刷新浏览器。

### 5.4 内置角色与自定义角色

- **内置角色**（staff、projManager、supervisor、deptLeader、sysAdmin）：不可删除，名称/描述跟随代码更新，权限可调整
- **自定义角色**：由系统管理员在角色管理中新增，默认继承一般人员权限，可按需扩展

## 6. 功能模块详解

### 6.1 工作台（OA 门户）

点击顶部 Logo 或登录成功后进入工作台。页面由四部分组成（自上而下）：

#### 6.1.1 问候语

工作台顶部为一条轻量欢迎徽章：左侧 46px 圆角方形头像位（主题蓝浅底 + 登录用户姓名首字），右侧文本组按时段显示问候语（早上好 / 上午好 / 中午好 / 下午好 / 晚上好）与用户姓名，下方附一行功能说明「统一入口 · 统一账号 · 统一权限」。该区域无卡片背景，直接置于页面底色上。

#### 6.1.2 板块磁贴

五大业务板块以**竖排大卡片**形式铺开，**按当前角色权限过滤**。卡片自上而下依次为：头部行（主题色图标 + 板块名称 + 右侧「N 子系统」计数）、模块描述、底部「进入板块 →」链接（悬停出现下划线），左侧带主题色竖条：

| 板块 | 主题色 | 包含子系统 |
|------|--------|-----------|
| 📁 项目管理 | 蓝 | 项目管理系统、项目看板（均为外部链接） |
| 🔬 研发公共 | 绿 | 标准库、经验案例库、自动化测试平台 |
| 📐 过程资产 | 青 | 开发规范、文档模板、设计规范、评审 Checklist |
| 📈 绩效管理 | 紫 | 考核模板管理、月度绩效考核、年度绩效管理（年度绩效考核 / 互评管理 / 我的互评任务 / 年终考核汇总）、结果查询 / 检索 |
| ⚙️ 系统管理 | 橙 | 账号管理、部门管理、角色管理、菜单管理、数据字典、日志与审计、通知公告（仅系统管理员） |

- 网格列数钳制在 **4~6**（`max(4, min(板块数, 6))`）：最多 6 个一行，不足 4 个板块也至少 4 列（卡片相应拉宽）；
- 窄屏自动降档（≤1200px 三列、≤768px 两列、≤480px 单列），响应式规则可正常覆盖内联列数变量。

点击板块磁贴进入**板块首页**，该板块下所有子系统磁贴一次性铺开，点击即进。子系统磁贴同为竖排小卡（图标+名称+外链标记头部行 / 菜单描述行 / 子项数行，描述取自 strings.js 的 `SUB_DESC` 静态文案表，最长两行省略；运行时新增菜单无描述时不显示该行），网格列数钳制在 **6~8**（`max(6, min(子系统数, 8))`）；外部子系统带「外链」标识，在新窗口打开。

#### 6.1.3 我的常用应用

将常用的子系统固定为磁贴（默认取前 4 个可见子系统），点击即进；「⚙ 管理」弹窗中勾选增删（最多 8 个），按账号持久化，换人换机各看各的。磁贴为竖排小卡（图标+名称头部行 / 板块名+外链标记行），8 列窄卡下名称不换行；网格列数钳制在 **6~8**（`max(6, min(应用数, 8))`）：最多 8 个一行，不足 6 个也至少 6 列；**外链子系统带「外链」标记**（浅蓝标签，磁贴上位于第二行右侧，管理弹窗中紧随名称），点击在新窗口打开。

#### 6.1.4 我的待办 ｜ 通知公告

工作台底部为左右双面板：

- **⚡ 我的待办**：按当前角色聚合跨模块待办（与右上角铃铛同源），点击条目直接跳转处理；完整待办清单可从右上角铃铛打开。
- **📢 通知公告**：展示系统发布的通知 / 公告 / 制度（置顶帖优先，默认展示最新 4 条），未读条目显示红点与未读数，点击阅读后自动标记已读。公告由系统管理员在「系统管理 → 通知公告」中维护。

#### 6.1.5 全局搜索

顶部搜索框输入关键词（回车触发），进入独立搜索结果页：

- **搜索范围**：研发公共（标准库 / 经验案例库）+ 过程资产（开发规范 / 文档模板 / 设计规范 / 评审 Checklist），按当前角色权限过滤；
- 结果按来源筛选（全部 / 标准库 / 经验案例库 / 各资产分类），标题与摘要中**关键词高亮**；
- 点击条目**弹窗查看详情**（标准元数据与正文、案例五段式、资产内容与检查项等），弹窗内可一键「进入」对应子系统；
- 搜索状态随路由持久化，刷新页面仍回到搜索结果页。

#### 6.1.6 待办提醒（右上角铃铛）

按当前角色聚合跨模块待办事项，登录后自动弹窗提醒，🔔铃铛角标实时显示待办数量：

| 角色 | 待办来源 |
|------|----------|
| 一般人员 | 我的考核表进度、我提交的案例审核状态 |
| 主管 | 下属的考核表（待主管打分） |
| 项目经理 | 下属/相关人员的考核表（待PM打分） |
| 部门领导 | 下属的考核表（待领导归档）、待审核案例 |
| 系统管理员 | 停用账号提醒 |

### 6.2 项目管理

项目管理模块包含**评审流程入口**与**外部子系统聚合**，当前包含以下入口：

| 子菜单 | 类型 | 目标地址 | 说明 |
|--------|------|----------|------|
| 📋 研发设计评审 | 内部 | — | 研发设计方案提交、评审与归档（功能建设中，入口先行） |
| 🚦 项目阶段评审 | 内部 | — | 项目阶段里程碑评审跟踪（功能建设中，入口先行） |
| 📁 项目管理系统 | 外部 | `http://192.168.1.19/devsuite/#home` | 公司内部项目管理平台 DevSuite |
| 📊 项目看板 | 外部 | `http://192.168.215.23/axshare/ppb/index.html` | 项目进度看板原型 |

内部评审入口点击后进入占位提示页（功能建设中的导航与权限演示）；外部入口点击后在新窗口打开对应系统，已打通 SSO 免二次登录（原型演示用）。

### 6.3 研发公共

研发公共模块是平台的核心知识库，包含**标准库**、**经验案例库**以及外部工具入口。

#### 6.3.1 📚 标准库

##### 功能概览

#### 6.5.2 📅 月度绩效考核

##### 考核流程

月度考核采用**项目经理 → 直接主管 → 部门领导**三级打分机制：

```
┌──────────────────────────────────────────────────────────┐
│  ① 项目经理打分                                          │
│  - 逐项填写任务项内容、PM 打分（0-100）、PM 评价          │
│  - 提交后锁定本表，进入下一环节                            │
├──────────────────────────────────────────────────────────┤
│  ② 直接主管打分                                          │
│  - 逐项填写主管打分（0-100）、主管评价                    │
│  - 系统自动取 PM 打分和主管打分的**最大值**填入领导打分栏  │
│  - 可对高分进行预填，也可手动调整                          │
├──────────────────────────────────────────────────────────┤
│  ③ 部门领导归档                                          │
│  - 最终审核确认                                           │
│  - 可打回（仅领导有此权限），退回指定考核人重改            │
└──────────────────────────────────────────────────────────┘
```

##### 表单字段说明

| 列名 | 说明 |
|------|------|
| 大类 / 小类 | 模板中定义的考核分类层级 |
| 考核标准 | 具体的考核项名称 |
| 权重 | 该项在总分中的占比 |
| 任务项 | 被考核人当月的具体工作任务描述 |
| PM 打分 | 项目经理给出的分数（0-100） |
| 主管打分 | 直接主管给出的分数（0-100） |
| 领导打分 | 部门领导最终确认的分数（预填为 PM/主管最大值） |
| PM / 主管 / 领导评价 | 各角色的评语（多行文本） |

##### 评分联动逻辑

系统自动同步 PM 打分和主管打分到领导打分预填值：
- 当 PM 打分和主管打分都填写后，**领导打分自动取两者的最大值**
- 支持手动覆盖预填值

##### 状态流转

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 考核表已创建 | 表已生成但未开始打分 | 无 |
| 待 PM 打分 | PM 尚未填写 | PM 可打分 |
| PM 已打分，待主管打分 | PM 已提交 | 主管可打分 |
| 主管已打分，待领导归档 | 主管已提交 | 领导可归档/打回 |
| 已打回 | 领导打回 | 相关考核人可重新编辑 |
| 已完成 | 领导已归档 | 任何人不可修改 |

#### 6.5.3 📊 年度绩效管理

年度考核、互评管理、我的互评任务与年终考核汇总同属年度绩效链路，合并为一个二级菜单「年度绩效管理」，下含四个三级子项：

##### 🎯 年度绩效考核

年度考核与月度考核流程完全一致（项目经理 → 主管 → 领导三级打分），区别仅在于：
- 使用**年度模板**（权重和考核标准不同）
- 考核期次为当年全年

##### 👥 互评管理

主管和项目经理专属，用于配置和管理互评人：

1. **批量配置互评人**：选择一个被考核人，指定若干同事作为其互评人
2. **查看互评提交进度**：哪些互评人已提交、哪些未提交
3. **计算互评平均分**：所有互评人分数的自动平均值

##### ✍️ 我的互评任务

主管和项目经理登录后，可以在这里看到**分配给自己的互评任务列表**：
- 待评价的同事
- 考核期次
- 状态
- 点击进入互评打分表单完成评价

##### 🏆 年终考核汇总

部门领导专属，年终自动生成：

1. **自动汇总当年月度成绩**：计算每位被考核人的全年月度平均分
2. **生成互评分**：互评平均分（来自「互评管理」子项）
3. **综合得分**：月度平均分 × 权重 + 互评分 × 权重
4. **排序**：按综合得分降序自动排序
5. **手工赋等级**：A / B / C / D（比例可按部门要求分配）

系统同时提供"强制生成年终得分"功能，确保所有人员都有最终结果。

#### 6.5.4 🔎 结果查询 / 检索

所有角色可查询考核结果：
- 支持按工号查询自己的历史考核结果
- 支持时间区间筛选
- 支持按关键词检索
- 展示：类型、期次、被考核人、汇总总分、考核结果等级、总评价、生成时间
- 数据**永久保存**，支持导出

- **新增子菜单**：在已有模块下添加二级/三级子菜单
- **菜单类型**：
  - `internal`（内部）：指向系统内置页面
  - `external`（外部）：点击后在新窗口打开指定 URL
- **业务级 Actions**：为菜单项声明支持的操作权限（view/add/edit/delete/export/admin）
- **排序**：通过 order 字段控制菜单项显示顺序

**持久化语义**（`oa_menus` 为唯一事实源）：
- 菜单管理中的新增 / 删除 / 改名 / 排序均写入 localStorage，**刷新后保留**，不会被种子数据恢复
- 种子同步按「指纹闸门」执行：`DEFAULT_MODULES` 的内容哈希存于 `oa_menu_seed_hash`，仅当代码里的种子相对上次加载发生过变更（发版）时才同步一次——注入种子新增的菜单、清理种子移除的菜单，完成后刷新指纹；种子未变更时完全尊重用户的运行时数据
- **删除墓碑**（`oa_menu_deleted_keys`）：用户删掉的种子菜单 key 会记入墓碑，后续发版同步不会把它重新灌回来
- 用户自建的菜单带 `custom` 标记，种子清理时不删除；用户改过的种子菜单带 `edited` 标记，种子元数据（名称/图标/排序/actions）不覆盖
- 删除菜单会同步清理所有角色的对应 perms

| 操作 | 影响 |
|------|------|
| 关闭浏览器标签页 | sessionStorage 全部数据丢失（会话、路由等） |
| 清除浏览器缓存 | 所有存储数据清空 |
| 切换浏览器 | 数据不共享 |


## 8. 常见问题解答

### Q1：刷新页面后为什么账号还在？

系统在登录成功后会将会话信息（`oa_session`）写入 sessionStorage，每次打开页面时优先从 sessionStorage 恢复登录状态。刷新页面不会清除 sessionStorage，所以账号保持登录。

### Q2：我登录后看不到标准库/绩效管理等菜单？

菜单按角色权限动态显示。请确认你的账号角色（可点击右上角头像查看）：
- 一般人员：可查看所有模块但无新增/编辑/管理员权限
- 如需权限变更，请联系系统管理员在「系统管理 → 角色管理 → 权限配置」中为你的角色授权

### Q3：为什么有些按钮（如"新建标准"）点不动？

这些按钮受**业务级 Action 权限**控制。每个菜单项声明了具体的操作权限（view/add/edit/delete/export/admin），只有你的角色拥有对应权限时按钮才会显示或可操作。系统管理员可在权限配置弹窗中调整。

### Q4：绩效考核表提交后还能修改吗？

**不能自行修改**。一旦 PM 或主管提交打分，本表会自动锁定并流转到下一环节。如需修改，需由上级角色执行**打回**操作（仅部门领导和系统管理员有打回权限），被打回的考核表会退回到上一环节重新编辑。

### Q5：经验案例库查重是怎么实现的？

目前原型阶段的查重机制是基于**标题指纹 + 附件哈希**的前端比对：
- 标题指纹：对标题文本进行归一化处理后计算相似度
- 附件哈希：对上传文件内容计算哈希值判断是否完全重复
- 发现疑似相似时会弹出相似度提示，用户确认非重复后仍可继续提交

### Q6：PDF 在线预览的水印能去掉吗？

**不能**，水印是前端在渲染时通过 CSS 叠加的，基于「当前登录用户名 + 时间戳」动态生成，旨在防止截屏泄密。这是安全设计，确保每个查看/下载行为都可追溯。

### Q7：如何添加新的角色或修改默认权限？

步骤：
1. 登录 admin 系统管理员账号
2. 进入「系统管理 → 角色管理」
3. 点击「+ 新增角色」（自定义角色）或选中已有角色点击「权限配置」
4. 在弹窗中勾选模块/子菜单/三级菜单的访问权限
5. 同时勾选叶子节点的业务级操作权限（查看/新增/编辑等）
6. 保存后自动对所有打开系统的页面生效

### Q8：外部系统（项目管理等）的地址在哪里配置？

在「系统管理 → 菜单管理」中，找到对应的外部子菜单项，修改其 `url` 字段即可。也可在源代码 `js/modules/config-menu.js` 的 `DEFAULT_MODULES` 中直接修改种子数据（改种子后所有用户会在下次加载时自动同步，用户删过的 key 除外，见 6.6.4）。

### Q9：如何重置所有数据？

方法一（推荐）：清除浏览器 localStorage 和 localStorage

```javascript
// F12 打开浏览器控制台，输入以下命令
localStorage.clear();
sessionStorage.clear();
location.reload();
```

方法二：清除浏览器缓存后重新打开页面，所有数据会重置为代码中的种子 Mock 数据。

### Q10：待办提醒弹窗能关闭吗？

可以。点击弹窗右下角的「知道了」按钮后，本次登录期间不再自动弹出。如需再次查看，点击右上角 🔔 铃铛图标即可。
