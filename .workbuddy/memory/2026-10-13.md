## 修复：header 搜索框被全局 input 样式覆盖（CSS 特异性陷阱）

**现象**：用户反馈工作台顶部搜索框样式未生效——实际渲染为白底灰边深色字的输入框，嵌在透明胶囊里。

**根因**：全局规则 `select, input[type="text"], … textarea`（style.css 105-123 行）特异性 **(0,1,1)**（属性选择器+元素），高于我写的单一类选择器 `.h-search-input` **(0,1,0)**——按 CSS 层叠规则全局胜出，强制注入 `background:#fff`、`border:1px solid var(--border)`、`color:var(--title)`、`padding:6px 9px`、`width:100%`；另全局 `input:focus`（0-1-1）还会叠加蓝色边框+光环。此为纯特异性问题，与源码顺序无关（类选择器永远打不过属性选择器）。

**修法**（仅 css/style.css）：`.h-search-input` 全部规则改用复合后代选择器 `.h-search .h-search-input`（**(0,2,0)**，类计数 2>1 胜出），并补 `width:auto`、`padding:0`、`box-shadow:none`；新增 `.h-search .h-search-input:focus`（0-3-0）压制全局 focus 蓝光环；加注释警示后人勿简化回单一类名。容器 `.h-search`（0-1-0）无竞争者，本就生效。

**验证（verify-css-cascade.js，自建静态层叠模拟器，无需浏览器）**：解析全部规则→对目标元素 input#globalSearchInput 计算匹配与特异性→按层叠决出胜出声明：12 项断言全过（背景 transparent/无边框/白字/无内边距/无阴影来自我的 0-2-0 规则；占位符半透明白；容器透明+264px；聚焦态无蓝光环；防回归检查单一类名写法不复现）。CSS 大括号配平 OK。

**教训（第五条，重要）**：本项目存在全局元素级输入框规则（0-1-1），**任何对 input 的类级覆盖（0-1-0）都会静默失效**——写在彩色/深色背景上的输入框必须用复合选择器或属性选择器抬特异性。此类问题无报错、只在浏览器可见，后续新增深色背景输入框务必先用层叠模拟器或 DevTools 核实。
